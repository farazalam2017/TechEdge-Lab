# 📚 Generative AI & AI Tools Bootcamp

Welcome to the official repository for the **Generative AI & AI Tools Bootcamp** conducted at **Buddha Institute of Management**.

This repository contains lecture notes, presentations, sample code, assignments, reference materials, and other learning resources shared throughout the course.

---

## 📌 Important Note

- The content in this repository is provided **solely for educational and knowledge-sharing purposes**.
- Students are encouraged to use these resources to enhance their understanding and practice beyond the classroom.
- The materials should not be reproduced or redistributed for commercial purposes without prior permission.

---

## 💻 Student Guidelines

To get the maximum benefit from this bootcamp, please follow these guidelines:

- **Bring your personal laptop** to every practical session. Most classes involve hands-on coding and AI application development.
- **Ensure you have a stable internet connection**, as many AI tools and APIs are cloud-based.
- **Actively participate** in discussions, coding exercises, quizzes, and project activities.
- **Practice after every class.** AI is a practical skill that improves through continuous experimentation.
- **Explore beyond the classroom.** Try different AI tools, read documentation, build mini-projects, and stay updated with the latest developments in AI.
- **Complete all assignments and projects** on time to strengthen your portfolio and practical skills.

---

## 🎯 Course Objective

By the end of this bootcamp, you will be able to:

- Understand the fundamentals of Generative AI and Large Language Models (LLMs).
- Use modern AI tools effectively.
- Write effective prompts using Prompt Engineering techniques.
- Integrate LLM APIs into applications.
- Build AI-powered applications.
- Understand the basics of RAG and AI Agents.
- Use AI-assisted development (Vibe Coding) to improve productivity.
- Develop industry-relevant AI projects for your portfolio.
